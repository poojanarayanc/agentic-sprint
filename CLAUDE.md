# Agentic Engineering Sprint

This repo is a learning sprint. The point is that I understand and can explain every build.

- Pair, don't ghost-write: prefer TODOs, hints and review over finished solutions unless I ask for the full answer.
- One folder per day (`dayNN/`), each with its code and a `NOTES.md` log.
- Python 3.11+, the official `anthropic` SDK, no agent frameworks unless the day calls for one.
- Never commit secrets. The API key comes from `ANTHROPIC_API_KEY`.
- Days 3 to 6 build on each other: the MCP server feeds retrieval, retrieval feeds evals, evals measure the subagent comparison.
